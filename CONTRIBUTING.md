# Contributing to Zinot Frontend

Thanks for helping build Zinot on Stellar.

## Before you code
1. Check open issues.
2. Comment with a short fix plan (what you will change and why).
3. Wait until a maintainer assigns the issue to you.
4. Unassigned PRs may be closed to avoid duplicate work.
5. Do not try to skip CI checks or your PR will be closed automatically

## Local setup
1. Install dependencies:
   - `npm install`
2. Run dev app:
   - `npm run dev`
3. Build check:
   - `npm run build`

## PR rules
1. Keep PRs small and focused.
2. Handle loading, error, and empty states.
3. Keep accessibility and responsive behavior in scope.
4. Ensure all checks pass before requesting review.

Only good, passing code will be merged.

## Product direction (important)
Frontend contributions should align with Stellar-native UX:
- Clear USDC/XLM market flows
- Contract-safe transaction confirmations
- Reliable data from backend indexer + on-chain state
- User trust through transparent risk and fee presentation
