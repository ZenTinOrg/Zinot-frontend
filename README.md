# Zinot Frontend

Frontend app for Zinot, a Stellar-native liquidity and lending protocol in progress.

## What this project is
This Frontend repo will let users view and manage Zinot markets built on Stellar:
- Supply and borrow flows for USDC and XLM markets
- Market health metrics (TVL, APR, utilization, risk)
- Wallet-driven interactions with Soroban contracts

The frontend consumes backend market/indexing APIs and contract state.

## Why this helps
Stellar gives fast and low-cost financial rails. Zinot aims to make those rails usable for everyday liquidity and credit actions through a clear web experience.

## Current status
Early build phase. Frontend repo scaffolding exists and will evolve as contract/backend logic matures.
